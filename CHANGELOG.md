## [Unreleased]

### Added
- Phase 11: background replacement. A Background view (open from a result, the gallery or an uploaded photo; P11 finds the subject automatically with a spinner and shows the mask overlay; **Refine mask** opens the mask editor seeded with the auto-mask (`MaskEditor.initialMask`); background sources: photo upload, **Describe** (generates a background from a prompt at the subject's closest aspect), flat colour or transparent PNG; blend: Harmonize Off/Light/Strong, colour match (on by default), edge feather, drop shadow; Advanced fit/position/size; live preview through `/api/background/preview`, which runs the same pipeline Apply saves). The `replace_background` step segments the subject (BiRefNet-lite ONNX on the CPU, `media/segment.py`, manifest entries `birefnet-lite` default and `birefnet` full, both MIT and hash-pinned) and composites in P11 (`media/composite.py`: fit/place, LAB colour match at a chosen strength, edge decontamination, feather, shadow, RGBA output for colour/transparent); `relight` adds a low-denoise harmonize pass over the seam band on the engine. New routes `POST /api/background/mask` and `/api/background/preview`. Save as Template offers "find the subject each run" (default for background runs) so a "product on my studio background" template re-runs on any new subject. Tuning and measurements on the laptop (`scripts/bench/background_tune.py`, `docs/P11_BENCHMARKS.md` -> Background replacement); Playwright: the Appendix B background path is 4 actions. ADR-0026, ADR-0027.
- Phase 10: inpainting. Mask editor (`frontend/src/features/mask-editor/`: brush and eraser, size with `[`/`]`, hardness, opacity, feather preview, invert, clear, undo/redo with Ctrl+Z/Ctrl+Shift+Z, wheel/pinch zoom, space- or middle-drag pan, pen pressure; greyscale PNG export at image resolution; 60 fps on 2560×1440) and an Inpaint view (open from a result, the gallery or an uploaded photo; prompt prefilled; Subtle fix / Change / Replace; "only masked area at full resolution"; Advanced denoise, mask blur, padding, steps, seed; Keep editing; Save as Template). The `inpaint` step compiles to core ComfyUI nodes (`recipe/steps/inpaint.py`); the runner grows and blurs the mask at full size, crops and scales the masked area to the model's working size and pastes the result back so unmasked pixels stay byte-identical (`media/inpaint.py`, `MaskPrep`); empty masks are refused at submit (`input.mask`). Save as Template can keep the mask in the template or ask for one each run. Presets tuned on 10 images on the laptop (`scripts/bench/inpaint_tune.py`, `docs/P11_BENCHMARKS.md` → Inpainting). Playwright: inpaint path 4 actions. ADR-0025.
- Phase 09: templates UI. **Save as Template** from a result or gallery detail (name from the prompt, folder, tags, new or fixed seed, optional "ask for the prompt each time"; 2 actions), server-side slot inference (`p11.templates.capture`, `POST /api/templates/from-image`) that keeps whole step chains and never stores bound photos, a Templates view (folders, tag filter, search, cards with the last output, Run, Inputs, Edit in Generate, Duplicate, Rename, Move, Export/Import of `.p11template.json`, Delete with Undo), a slot form with photo picker or drag-and-drop and remembered inputs, a Ctrl+K template palette and last-five chips in Generate, and six starter templates (`templates/starter/`: wallpaper photoreal 1080p and 1440p, software logo dark and light, indie game logo, 3D animated avatar) installed once on first `p11 serve`. Template list entries carry `last_image`; `api()` handles 204. Playwright action counts: save 2, re-run 1, one-slot run 3. ADR-0024.
- Phase 08: Studio UI. App shell (left nav with placeholders for Phases 09–14, top bar, status bar with engine state, queue, VRAM, GPU temperature band and current model, light/dark themes), typed API client and SSE store with reconnect, Generate view (prompt, style chips, size presets, batch 1–4, Ctrl+Enter, live progress with stage, step and ETA, Cancel/Esc), Advanced drawer (model with family and default badge, LoRAs, negative prompt, sampler, scheduler, steps, CFG with manifest defaults, seed lock, upscale chain), result panel (zoom/pan, metadata, Variations, Tweak prompt, Upscale ×2, Favourite, Download with "strip metadata"), gallery (virtualized day grid, search, template/model/favourite filters, detail view, synced compare, open as recipe, bulk ZIP export, delete to trash, Empty trash), plain-English toasts, keyboard map with a `?` overlay. API: `POST /api/images/{id}/variations`, `DELETE /api/images/{id}`, `GET /api/trash`, `POST /api/trash/empty`, `GET /api/gallery/facets`, `POST /api/gallery/export`, `model` gallery filter, SSE `deleted`, registry defaults in `/api/models` (ADR-0023). Playwright walkthroughs with Appendix B action counts, a network guard and axe checks; screenshots in `docs/images/`.
- Phase 07: Studio API and lifecycle. `SecurityMiddleware` (Host allowlist, Origin/`Sec-Fetch-Site` checks, per-launch session token with one-time launch codes and a read-only `HttpOnly` cookie, strict CSP and security headers, body caps); routes for jobs, SSE events, gallery (paging, prefix search, template/favourite/date filters, thumbnails, favourite, export with metadata strip, recipe), uploads (content-validated images and videos, EXIF/GPS and container metadata stripped, generated names), templates CRUD/import/export, presets, models and system; a persisted job queue with one GPU worker (lazy engine start, idle stop, low-VRAM reset, cancel, thermal pause, interrupted jobs marked after a restart) and a runner that chains steps, saves, embeds and indexes every output; plain-English `{code, message, hint}` errors; `p11 serve/start/stop/status/open/doctor` (Omarchy app-window launch, doctor checks for GPU, engine pin, torch/sm_75, models, ports, disk, permissions); JSON Studio log with secret redaction; `p11 serve --fake` demo gallery in its own sandbox; the placeholder page redeems the launch code. ADR-0022.
- Phase 06: model manager. Hash-pinned `models/manifest.toml` (Phase 03's default set and the SD 1.5 `full` entries, each re-verified at Hugging Face with its check timestamp), strict manifest schema, HTTPS-only resumable downloader with streaming SHA-256, manual redirects that never forward a token to another host, retries, disk-space and per-host limits; licence acknowledgements in `~/.config/p11/licences.toml`; content-based format sniffing with pickle refusal (S4) and safetensors kind/base detection; `ModelManager` registry (installed/missing/corrupt/user-added/unregistered, join by hash, enable/disable, remove, `--from` reuse of existing downloads, `extra_model_paths.yaml`) and the compiler's `ManagerRegistry`; `p11 models list|install|verify|add|remove|enable|disable|licences` with `--json`; `p11.models.check()` for `p11 doctor` and `p11.problems.Problem`. ADR-0021.
- Phase 05: engine adapter. `p11.engine.Engine` protocol with typed events and errors; `ComfyEngine` over the pinned ComfyUI v0.43.0 (endpoints and messages read from the pinned source, version and loopback check at start, per-run websocket, outputs fetched and deleted from the engine scratch dir); `ProcessSupervisor` (GPU lock for the engine's lifetime, pid file + port check, parent-death signal, rotated `~/.cache/p11/logs/engine.log`, one restart after a crash, SIGTERM → SIGKILL stop); `run_with_oom_retry` (free memory, restart in `--lowvram`, retry once, plain-English error); `FakeEngine` and `p11 serve --fake`; GPU telemetry (`nvidia-ml-py` NVML with `nvidia-smi` fallback, ≤ 1 Hz) and `ThermalGuard`; one contract suite run against the fake, a mock ComfyUI server and the real engine (forced OOM with a VRAM hog); `scripts/bench/adapter.py` (20 back-to-back wallpapers, overhead within noise, interrupt 0.52 s). ADR-0020. Dependency: nvidia-ml-py 13.615.71 (BSD-3-Clause).
- Phase 04: recipe core. Recipe schema v1 with migrations (`p11.recipe.model`, `p11.recipe.migrate`), the preset table (wallpaper, square, logo and avatar presets; photoreal, 3D animated avatar, flat and 3D logo styles; Phase 03 buckets, chains and sampler defaults), the pure recipe → ComfyUI compiler with the `register_step`/`register_modifier` extension point (generate and upscale steps; ADR-0019), seed strategies, seed and prompt variations, output layout (`~/Pictures/P11/YYYY-MM-DD/<template|adhoc>/…`, `0700`), run sidecars and recipes embedded in PNG `iTXt` chunks with metadata stripping for export, the SQLite gallery index with FTS5 prompt search, and the JSON template store with import/export. 20 golden graphs, Hypothesis property tests, a coverage gate (≥ 90 % for `recipe/`, `outputs/`, `templates/`) in `make test`, and a `gpu` test that runs a compiled 1920×1080 graph on the pinned engine.
- Phase 03: pinned headless ComfyUI v0.43.0 engine (`engine/engine.lock.toml`, hash-locked `engine/requirements.lock.txt`, `extra_model_paths.yaml` template) installed by the idempotent `scripts/engine_setup.sh` into its own uv CPython 3.12 venv with torch 2.14.1+cu130 verified on sm_75; bake-off harness `scripts/bench/`; `docs/P11_BENCHMARKS.md` (native, avatar, wallpaper presets, VRAM modes, 50-run stability, 10-minute thermals, network check); ADR-0018 default model set (RealVisXL V5.0 Lightning, Juggernaut XL v9, fp16-fix SDXL VAE, 4×NomosWebPhoto RealPLKSR; 14.4 GB); ADR-0002/0008/0009/0010 confirmed; `gpu` engine smoke test and bench schema unit test.

### Changed
- Phase 11: `ReplaceBackground` grows additively (optional `background_slot` + `background_colour` exactly one of; `mask_png`, `colour_match_strength`, `prompt`/`negative`, `fit`, `background_x`/`background_y`, `subject_scale`, `subject_x`/`subject_y`, `shadow`; `mask_mode: auto` takes no mask); older v1 documents still load. The compiler's `compile()` now returns plan items (`EngineGraph | LocalStep`) and `register_plan_step` covers steps that are local work with an optional engine tail (`GraphInput` gains `local` sources); the runner executes local steps in `p11.media` and saves only a step's last output. `POST /api/templates/from-image` takes `mask: auto|slot|fixed`. `MaskEditor` gains `initialMask`. The default model set grows by `birefnet-lite` (14.41 GB -> 14.63 GB, within the 30 GB budget; recorded in the manifest and ADR-0026).
- Phase 10: `Inpaint` gains optional `mask_png`, `mask_blur_px`, `crop`, `padding_px` and `sampler` and `mask_slot` becomes optional (exactly one of `mask_slot`/`mask_png`); older v1 documents still load, so no schema version bump (ADR-0025). `EngineGraph` gains `prep`, `GraphInput` gains `inline` inputs and `kind`; `POST /api/templates/from-image` takes `mask: slot|fixed`; template slot uploads of `mask` slots go up as `kind=mask`; the Inpaint nav entry and result/gallery Inpaint button are live (`NavProvider.edit`).
- Phase 09: the Templates nav placeholder and the `LATER.template` stub are replaced; template export files are named `<slug>.p11template.json` (was `.p11.json`); `create_app(starters=…)` and `Studio.starters` install the bundled starters (off unless `p11 serve`); the gallery route helpers `entry_file` and `run_record` are shared with the templates route.
- Phase 08: the placeholder page is replaced by the Studio UI; `GalleryIndex.delete` clears the parent link of children; `search`/`search_count` take `model`.
- Phase 07: `create_app()` takes settings, session, port and paths and always has an engine (the pinned ComfyUI unless `fake`); the gallery index gains `since`/`until` filters and `search_count`; the FakeEngine returns one image per batch item, like ComfyUI; new settings `engine_idle_stop`, `video_warn_seconds`, `video_warn_height`; the Playwright e2e runs against `p11 serve --fake` in temp dirs; the coverage gate includes the API, jobs, media, lifecycle, doctor and logging modules; dev dependency `httpx2` (BSD-3-Clause) removes Starlette's `TestClient` deprecation warning (open since Phase 02).
- Phase 06: the `models` CLI stub is replaced; the coverage gate includes `p11.models`; `p11.recipe.registry.ModelKind` gains `facedetect`; `PROVISIONAL_DEFAULT_SET` is now a test fixture kept equal to the manifest by a test.
- Phase 05: thermal guard defaults are 87 °C pause / 80 °C resume (owner question 5, H9; were 83 / 75 placeholders) and must satisfy resume < pause; the Phase 04 compiled-graph `gpu` test runs through `ComfyEngine`; the coverage gate in `make test` now includes `p11.engine` and `p11.gpu`.
