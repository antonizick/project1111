## [Unreleased]

### Added
- Phase 05: engine adapter. `p11.engine.Engine` protocol with typed events and errors; `ComfyEngine` over the pinned ComfyUI v0.43.0 (endpoints and messages read from the pinned source, version and loopback check at start, per-run websocket, outputs fetched and deleted from the engine scratch dir); `ProcessSupervisor` (GPU lock for the engine's lifetime, pid file + port check, parent-death signal, rotated `~/.cache/p11/logs/engine.log`, one restart after a crash, SIGTERM → SIGKILL stop); `run_with_oom_retry` (free memory, restart in `--lowvram`, retry once, plain-English error); `FakeEngine` and `p11 serve --fake`; GPU telemetry (`nvidia-ml-py` NVML with `nvidia-smi` fallback, ≤ 1 Hz) and `ThermalGuard`; one contract suite run against the fake, a mock ComfyUI server and the real engine (forced OOM with a VRAM hog); `scripts/bench/adapter.py` (20 back-to-back wallpapers, overhead within noise, interrupt 0.52 s). ADR-0020. Dependency: nvidia-ml-py 13.615.71 (BSD-3-Clause).
- Phase 04: recipe core. Recipe schema v1 with migrations (`p11.recipe.model`, `p11.recipe.migrate`), the preset table (wallpaper, square, logo and avatar presets; photoreal, 3D animated avatar, flat and 3D logo styles; Phase 03 buckets, chains and sampler defaults), the pure recipe → ComfyUI compiler with the `register_step`/`register_modifier` extension point (generate and upscale steps; ADR-0019), seed strategies, seed and prompt variations, output layout (`~/Pictures/P11/YYYY-MM-DD/<template|adhoc>/…`, `0700`), run sidecars and recipes embedded in PNG `iTXt` chunks with metadata stripping for export, the SQLite gallery index with FTS5 prompt search, and the JSON template store with import/export. 20 golden graphs, Hypothesis property tests, a coverage gate (≥ 90 % for `recipe/`, `outputs/`, `templates/`) in `make test`, and a `gpu` test that runs a compiled 1920×1080 graph on the pinned engine.
- Phase 03: pinned headless ComfyUI v0.43.0 engine (`engine/engine.lock.toml`, hash-locked `engine/requirements.lock.txt`, `extra_model_paths.yaml` template) installed by the idempotent `scripts/engine_setup.sh` into its own uv CPython 3.12 venv with torch 2.14.1+cu130 verified on sm_75; bake-off harness `scripts/bench/`; `docs/P11_BENCHMARKS.md` (native, avatar, wallpaper presets, VRAM modes, 50-run stability, 10-minute thermals, network check); ADR-0018 default model set (RealVisXL V5.0 Lightning, Juggernaut XL v9, fp16-fix SDXL VAE, 4×NomosWebPhoto RealPLKSR; 14.4 GB); ADR-0002/0008/0009/0010 confirmed; `gpu` engine smoke test and bench schema unit test.
- Phase 00: specification with amendments, ADR log, implementation plan, phase prompts, agent rules.
- Phase 01: MIT `LICENSE` and `NOTICE`; `README.md`, `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md` (Contributor Covenant 2.1), `THIRD_PARTY_NOTICES.md` skeleton; `.gitignore`, `.dockerignore`, `.editorconfig`; pre-commit with gitleaks and basic hooks; `.github/` (CI with a gitleaks job, issue and PR templates, Dependabot); docs skeleton (`P11_ARCHITECTURE.md`, `P11_USER-GUIDE.md`); private GitHub repository `antonizick/project1111`.
- Phase 02: `p11` package on uv-managed CPython 3.12 (`pyproject.toml`, `uv.lock`); Typer CLI (`version`, `paths`, `serve`, stubs); FastAPI app factory with `/healthz` and static serving; XDG `paths.py`, `config.py` (loopback-only host), advisory `gpulock.py`; Vite + React + TypeScript frontend with Vitest and a Playwright smoke test, built into `src/p11/web/`; `Makefile` (`setup`, `tools`, `lint`, `typecheck`, `test`, `gpu-test`, `e2e`, `build`, `audit`, `check`); CI job running `make check`; Dependabot for uv and npm.

### Changed
- Phase 05: thermal guard defaults are 87 °C pause / 80 °C resume (owner question 5, H9; were 83 / 75 placeholders) and must satisfy resume < pause; the Phase 04 compiled-graph `gpu` test runs through `ComfyEngine`; the coverage gate in `make test` now includes `p11.engine` and `p11.gpu`.
